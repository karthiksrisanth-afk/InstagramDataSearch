# Build the APK using only your phone

1. Download and extract this ZIP.
2. In your phone browser, open GitHub and create a new repository.
3. Upload the contents of this folder, including `.github/workflows/android-apk.yml`.
4. Open the repository's **Actions** tab.
5. Select **Build Android APK** and tap **Run workflow**.
6. Wait for the green checkmark.
7. Open the completed workflow and download the **InstagramDataSearch-debug-apk** artifact.
8. Extract it if your browser downloads it as a ZIP, then tap `app-debug.apk`.
9. Allow your browser/file manager to install apps when Android asks, then install.

This version launches in local demo mode and does not require Instagram credentials.
